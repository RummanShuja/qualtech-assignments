# Qualtech Assignments

A collection of small frontend projects and practice assignments built while learning HTML, CSS, JavaScript, React, and related tools.

## Projects

| Folder | Description | Tech Stack |
| --- | --- | --- |
| [`formik_form/`](./formik_form/) | Loan application form with validation, localStorage persistence, and a summary dashboard. | React, Formik, Yup, Vite |
| [`login_page/`](./login_page/) | Responsive login-page UI with a split-screen layout. | HTML, CSS |
| [`react-redux/`](./react-redux/) | Counter app to practice Redux store, slices, and React-Redux hooks. | React, Redux Toolkit, Vite |
| [`react-todo/`](./react-todo/) | Simple todo app to add, complete, and delete tasks. | React, CSS, Vite |

## Running a Project

Each project is independent. For the React projects, open the relevant folder and run:

```bash
npm install
npm run dev
```

For `login_page`, simply open `index.html` in a browser.

## Notes

These projects are for learning and practice. See the README in each project folder for more details.

# miFIN - Login Page

A modern, responsive login interface for **miFIN**, a compliance-ready Loan Management System (LMS) built by **Qualtech** for NBFCs, MFIs, and banks.

---

## 🚀 Features

- **Split-Screen Design**:
  - **Left Showcase Panel**: Product highlights, BFSI statistics, product tags (LEAD, LOS, Collection, Connect AI, Finly), and branding.
  - **Right Authentication Card**: Clean, elevated card containing the login form and partner branding (ABC Bank).
- **Background Video**: Dynamic looping background video for an engaging visual experience.
- **Authentication Options**: Tabbed interface supporting **miFIN**, **SSO**, and **MFA**.
- **User Form Controls**:
  - Username and Password fields (with password visibility toggle icon).
  - Captcha verification box.
  - "Remember me" checkbox and "Forgot password" recovery link.
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices using CSS Flexbox and Grid.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup structure.
- **CSS3**: Custom styling, Flexbox, Grid, and Media Queries for responsive design.
- **Google Fonts**: [Inter](https://fonts.google.com/specimen/Inter) typography.
